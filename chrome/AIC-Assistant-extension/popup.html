사용 방법
1. 추천 팀 편성 페이지를 엽니다.
2. 페이지에서 “내 데이터 동기화”를 ON으로 변경합니다.
3. 데이터가 감지되면 “AIC-Assistant에 공유하기”를 누릅니다.
전송되는 정보
  • roleId
  • 캐릭터/무기 보유 데이터
  • 동기화 시간
전송하지 않는 정보
  • 쿠키, token, cred, sign
  • 로그인 정보
  • 요청 헤더 전체
